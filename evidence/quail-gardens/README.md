# Quail Gardens Dr

Encinitas Blvd to Leucadia Blvd. Restriping, new stop signs at Kristen Ct and Via Zamia, and a quick-build **mini-roundabout at Ecke Ranch Rd**. Part of the city's emergency bicycle safety program (local emergency ratified June 28, 2023). Construction Aug 2024 to Sep 2025.
