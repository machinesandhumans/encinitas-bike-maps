# Advocate reports (unofficial)

Crash lists, accounts, photos and videos collected by riders and advocates. Kept apart from official data on purpose: these catch crashes the state database misses (especially solo falls), but none is verified until matched to a record or corroborated.

## How to file one

Save the raw list here as `cardiff-<who>-<YYYY-MM-DD>.csv` (or .json / .pdf) with: date, approximate location, direction, what was hit (wheel stop, post, curb, car, pedestrian, other rider), injury, source (who reported it, link), and `ccrs_match` (CCRS collision_id if one matches, blank if not). Keep the original file unedited alongside any cleaned version.

On maps, advocate crashes go in their own layer with their own color and the label "Reported by advocates, not in state records."
